# CI/CD Integrated Automated PR Review & Test Generation Bot
Reference PR QA bot implementing GitHub webhook HMAC verification primitives, Python-file diff discovery, AST function analysis, edge-case test patch generation, candidate-branch Contents API request construction, coverage-delta calculation, Docker and CI.

The repository does not push to a live GitHub repository during tests. A “25% branch coverage increase” is not established by this code; retain that resume metric only with measured before/after repository coverage.
